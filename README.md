# 🥗 Giovanna Nutri — Nutrição Clínica e Esportiva

**Site institucional de uma nutricionista fictícia, com foco em saúde, alimentação equilibrada e desempenho esportivo.**

## 📌 Sobre o Projeto

O **Giovanna Nutri** é um projeto de desenvolvimento Front-End que consiste na adaptação e personalização de uma estrutura de site preexistente para criar uma página institucional de uma nutricionista fictícia, com atuação nas áreas de Nutrição Clínica e Esportiva.

O projeto recebeu ajustes visuais, organização de conteúdo e personalizações com o objetivo de apresentar os serviços oferecidos, os diferenciais do atendimento e as informações profissionais de forma moderna, intuitiva e agradável.

## 🚀 Funcionalidades

- Apresentação profissional da nutricionista.
- Seção de serviços nutricionais.
- Apresentação dos diferenciais do atendimento.
- Histórias ilustrativas de transformação.
- Informações sobre formação acadêmica e abordagem profissional.
- Botão de agendamento com direcionamento para WhatsApp.
- Layout organizado e navegação intuitiva.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** estruturação e organização do conteúdo.
- **CSS3:** estilização, layout e identidade visual.
- **JavaScript:** implementação de interações e funcionalidades.

## 🎯 Objetivo do Projeto

Aplicar e aprimorar conhecimentos em desenvolvimento Front-End por meio da adaptação e personalização de uma interface web, explorando conceitos de estruturação semântica, estilização, organização de código e experiência do usuário.
